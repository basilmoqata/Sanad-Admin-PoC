# 🏛️ مشروع منصة سند - لوحة تحكم المسؤول (Sanad Admin Dashboard PoC)

نموذج إثبات مفهوم (Proof of Concept) مُطور لصالح **دائرة الأحوال المدنية والجوازات** لإدارة ومتابعة طلبات الخدمات الإلكترونية عبر المساعد الصوتي والواجهة الرقمية.

---

## 🚀 المميزات الرئيسية
* **واجهة مسؤول مرتبة:** استعراض الطلبات المقدمة وقبولها أو رفضها فوراً.
* **إدارة حالات الطلبات:** تحديث حالة الطلب تلقائياً في قاعدة البيانات (`Pending`, `Approved`, `Rejected`).
* **خفيف وسريع:** مبني باستخدام إطار العمل **Flask** وقاعدة بيانات **SQLite**.

---

## 🛠️ تقنيات المشروع (Tech Stack)
* **Backend:** Python 3.11, Flask
* **Database:** SQLite3
* **Frontend:** HTML5, CSS3, Jinja2 Templates
